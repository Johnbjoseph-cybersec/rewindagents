01Pricing

The tool is free. Cloud is planned.

What exists is open source. What is planned has no price and is not for sale.

Open source Apache-2.0

Free

Everything the tool does today.

  • The recorder and hooks for 7 coding agents: every tool call in a hash-chained log, every file saved before it changes
  • fork any recorded step and compare the runs, with your own --check
  • replay, rewind and branch, and verify against a pinned head
  • export: one session as one HTML page, with the diff each step made
  • sessions: every session in the log, and search by command or path
  • Runs on your machine. Standard library only. No account.

Cloud planned

Not yet priced

Hosted and opt-in, for teams; the local tool never needs it. Not for sale yet. No price has been set, so none is shown. If you want it, open the waitlist issue on GitHub and say what you would pay for.

  • A shared page per comparison, linkable from a pull request or a chat
  • Saved starting points run in parallel cloud sandboxes, so ten attempts do not occupy a laptop
  • A team's comparison history across repos and people: which agent, model or prompt wins on which kind of task
  • Scheduled re-runs of a team's starting points when a model, prompt or CLAUDE.md changes, with a report of what got worse
  • Retention, SSO, seats: the things an organisation buys

02Questions about paying

Before you ask.

Will the open-source tool stay free?

The code you have is Apache-2.0, and that licence cannot be withdrawn from it. Nothing that exists today is behind a paywall: the recorder, the hooks, replay, rewind, branch, fork, compare, export and sessions are all in the open-source tier, and what an individual developer needs stays there.

What would Cloud add?

Things that need a service rather than a command, for a team: a shared page per comparison you can link from a pull request, saved starting points run in parallel sandboxes instead of on a laptop, a history of which agent, model or prompt did best on which kind of task, and re-runs when a model or prompt changes. It is opt-in: the local tool never needs it and still makes no network connection. None of it is built yet. fork and compare are the local halves and are free.

How does the waitlist work?

It is a GitHub issue on the repository with the label waitlist, as the README says. Say what you would pay for. There is no form, no email list and no tracking on this site.

Can my company get an invoice or a quote today?

No. Nothing is for sale yet. When Cloud exists, this page will carry the price and a checkout link, and the link will live in one config key until then.
