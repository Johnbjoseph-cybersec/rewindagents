# brand/vsl/audio: sources and licences

| file | what | licence | attribution |
|---|---|---|---|
| make_bed.py | generator of the three music beds and the two SFX (vendored from the Creative Studio's studio/sound_rewind_bed.py, round 3) | original: our own work, in this repository under its Apache-2.0 licence | none owed |
| sound_dsp.py | shared DSP the generator uses: filters, loudness, true peak, limiter, synthetic reverb (vendored from the Creative Studio's studio/sound_dsp.py) | original: our own work, in this repository under its Apache-2.0 licence | none owed |
| bed-vsl-90s.wav, bed-vsl-30s.wav, bed-vsl-15s-vertical.wav, sfx-rewind.wav, sfx-tick.wav | generated by make_bed.py; not committed (.gitignore), rebuilt by brand/vsl/render.py when missing, sha256 pinned in brand/vsl/manifest.json | original | none owed |
| sections.json | the generator's per-section report (bars, tempo, chords) | original | none owed |

No download, no sample, no loop, no third-party audio: every sound is synthesised from sines, additive saw partials and filtered
noise with fixed seeds; the reverb is a synthetic noise impulse response. Nothing is registered with Content ID. The Creative
Studio records the same in its own audio/LICENSES.md (its section on these films' bed, dated 2026-11-12). Third-party code the generator imports
at run time (not vendored): numpy, scipy (BSD-3-Clause), pyloudnorm (MIT), soundfile (BSD-3-Clause); versions in requirements.txt.
