# rewindagents: waitlist welcome

The waitlist is a GitHub issue on the repository with the label `waitlist` ({waitlist_url} opens one). There is
no mailing list and nothing sends this automatically. Post it by hand as a reply on the person's waitlist issue;
if they left an email address in the issue and asked to be written to, the same text can go by email from John's
address. Send it once. Fill the addresses with `python3 brand/launch/fill.py waitlist-welcome.md`.

## Subject

You are on the rewindagents waitlist

## Body

Hi,

Thanks for adding yourself to the waitlist. Here is exactly where things stand, so you know what you signed up for.

The paid Cloud tier is planned, not built and not priced. What it would add: cloud sync of session history across machines, shareable replay links, long retention and session search. Nothing is for sale yet.

What you can use today, free and open source: the recorder, the hooks, and `rewindagents replay`, `rewindagents rewind 12` and `rewindagents branch 12 --name try2`. There are also local halves of three of those planned Cloud ideas: `rewindagents export` writes a session as one HTML page, `rewindagents sessions --grep config.py` searches the sessions in a log, and `rewindagents bundle --out s1.bundle` with `rewindagents import s1.bundle` carries a session to another machine as one file.

One question, and your answer decides what gets built first: which of those planned features would you pay for, and what would it have to do that the local commands do not? Reply on the issue (or to this email) in a sentence or two.

If you would rather not hear about it again, say so and you will not.
